# Post-race Review

Confirm the activity is a race before writing it as one. Review splits,
execution against any planned tactic, heart-rate pattern, conditions, athlete
narrative, and uncertainty. Update records and Coach Model only when the
evidence supports them.

Define recovery before quality work resumes. Send the review to
`running-journal-sync`; a next-block decision belongs to `running-plan-design`
or `running-plan-adaptation`, never to this review alone.
