# Pattern Review

Read generated history and relevant journal entries before promoting evidence.
Mark a single observation as a candidate, promote only repeated evidence into
the Coach Model in `athlete-profile.md`, and retire patterns contradicted by
later evidence. Keep objective data primary for physiological interpretation;
pain, injury, and an explicit athlete limit override it for safety.

Do not change the plan directly. Hand a justified load or safety change to
`running-plan-adaptation`; hand a new or replacement block to
`running-plan-design`.
