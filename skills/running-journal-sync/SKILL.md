# Journal Sync

Use `coaching/journal/` unless the user configured an alternate local journal
root. Add rather than overwrite athlete-authored text. Keep narrative verbatim;
record coach facts and interpretation in a clearly separate section. Do not
copy raw CSV or generated history.

Write one concise entry for each reviewed session or race. Once an ISO week
has closed, add one whole-week synthesis that links journal evidence with the
weekly Garmin aggregates. Associate optional voice feedback only when its
session is unambiguous; otherwise ask the athlete. Hand material decisions to
`coaching/coach-log.md` and evidence suitable for trends to
`running-pattern-review`.
