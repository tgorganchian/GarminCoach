# Session Review

Read the activity facts, relevant laps, profile, generated history, active plan
when present, and nearby journal entries. Separate objective facts,
interpretation, uncertainty, athlete narrative, and safety signals. Name data
freshness limits instead of inventing precision.

Do not establish a lasting pattern, silently change the plan, or write a race
interpretation. Send every completed review to `running-journal-sync` with the
session date, factual reading, uncertainty, and any athlete-authored words.
